# FEFO 로트매칭 Google Apps Script 설치 가이드

## 📋 개요

이 스크립트는 본비반트 ERP의 **FEFO (First Expired First Out)** 로트매칭을 자동화합니다.
생산 시 어떤 로트의 원료를 사용했는지 자동으로 계산하여 추적성을 확보합니다.

## 🔧 설치 방법

### 1단계: Apps Script 열기

1. Google Sheets 스프레드시트 열기
2. 메뉴: **확장 프로그램** → **Apps Script** 클릭
3. 새 프로젝트가 열립니다

### 2단계: 코드 복사

1. `fefo-lot-matching.gs` 파일의 전체 내용을 복사
2. Apps Script 편집기에 붙여넣기
3. 파일명을 `FEFO로트매칭.gs`로 변경 (선택사항)

### 3단계: 저장 및 권한 승인

1. **Ctrl + S** 또는 💾 아이콘으로 저장
2. 처음 실행 시 권한 승인 필요:
   - "승인 필요" 팝업에서 **권한 검토** 클릭
   - Google 계정 선택
   - "고급" → "프로젝트명(안전하지 않음)으로 이동" 클릭
   - **허용** 클릭

### 4단계: 트리거 설정 (선택)

자동 실행을 원하면 트리거 설정:

1. Apps Script 왼쪽 메뉴에서 ⏰ **트리거** 클릭
2. **트리거 추가** 클릭
3. 설정:
   - 실행할 함수: `runFEFOLotMatching`
   - 이벤트 소스: `시간 기반`
   - 시간 기반 트리거 유형: `일 단위 타이머`
   - 시간대 선택: `오전 6시 ~ 7시`
4. **저장**

## 🚀 사용법

### 메뉴에서 실행

스프레드시트 상단에 **📦 FEFO 로트관리** 메뉴가 추가됩니다:

- **🔄 오늘 로트매칭 실행**: 오늘 생산분에 대해 FEFO 로트매칭 실행
- **📅 기간별 로트매칭**: 특정 기간의 로트매칭 일괄 실행
- **📊 로트별 재고 새로고침**: 현재 로트별 재고 현황 업데이트
- **⚠️ 만료 임박 알림**: 유통기한 7일 이내 원료 확인
- **ℹ️ 도움말**: 사용법 안내

## 💡 FEFO 로직 설명

1. **유통기한 순 정렬**: 각 원료의 로트를 유통기한 오름차순으로 정렬
2. **선순위 차감**: 가장 빨리 만료되는 로트부터 사용량 차감
3. **복수 로트 사용**: 하나의 로트로 부족하면 다음 로트 사용
4. **부족분 추적**: 재고 부족 시 `SHORTAGE` 표기

## ⚠️ 주의사항

1. **BOM 마스터 필수**: BOM 데이터가 없으면 로트매칭 불가
2. **날짜 형식**: `YYYY-MM-DD` 형식 권장 (예: 2026-06-05)
3. **수량 단위**: 입고는 kg, BOM은 g/EA 사용
4. **유통기한 미입력**: 유통기한 없는 로트는 FEFO에서 후순위

## 🔍 문제 해결

### "BOM마스터 시트가 필요합니다" 오류
→ BOM마스터 시트를 먼저 생성하고 데이터 입력

### 로트매칭 결과가 없음
→ 생산실적_RAW에 해당 날짜의 데이터가 있는지 확인

### 권한 오류
→ Apps Script에서 권한 재승인 필요
