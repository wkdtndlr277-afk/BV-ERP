1. 시스템 개요

1.1 프로젝트 소개

본비반트 HACCP ERP는 베이커리 생산 관리 및 HACCP(식품안전관리인증기준) 준수를 위한 통합 ERP 시스템입니다. Cloudflare 엣지 네트워크 상에서 운영되어 빠른 응답 속도와 안정성을 보장하며, Google Sheets를 SSOT(Single Source of Truth)로 활용하여 관리자가 직접 데이터를 확인·수정할 수 있는 하이브리드 구조입니다.

프로젝트명 (Git/Cloudflare)haccp-erp / bv-erp
현재 버전v3.6.50
배포 플랫폼Cloudflare Pages (Edge Runtime)
주 데이터 저장소Google Sheets (Sheet ID: 1aEvc4673J0wZoPuojwgrxVu7qhkR5VuymmlKPdHpNfU)
보조 데이터 저장소Cloudflare D1 (SQLite) - haccp-erp-production
운영 도메인https://bv-erp.pages.dev

1.2 주요 기능

  • 생산 관리: 일별 생산실적 등록, 로트(LOT) 관리, BOM 기반 원료 소요량 자동 계산
  • 재고 관리: 일별수불부 자동 생성, 원료 입고/사용/재고 실시간 추적
  • 바코드 시스템: 생산 바코드 자동 발급 및 스캔 이력 관리
  • HACCP 관리: 공정 품질 검사, 미생물 검사, KPI 표준 관리
  • 원가 관리: 상세 원가 계산, 재료비 트래킹
  • 발주/입고: 주문 업로드, 입고 처리, 원료마스터 관리
  • 일일 보고서: 자동 집계 및 대시보드 시각화

1.3 사용자 및 이해관계자

  • 관리자 (super_admin): 시스템 전체 관리, 사용자 권한 설정
  • 생산 담당자: 일일 생산실적 등록, 로트 관리
  • 품질관리자: HACCP 검사 기록, 미생물 검사 결과 입력
  • 대표이사 (인수 예정): 계정 이관 후 최종 소유자

컬럼필드명설명

4.2.2 로트매칭

생산실적을 BOM에 따라 원료별로 분해한 상세 사용 내역입니다.

  • 생산일자, LOT번호, 제품코드, 제품명, 생산수량
  • 원료코드, 원료명, BOM비율, 사용량, 단위

4.2.3 생산실적

일별 제품 생산 실적을 기록합니다. 사용자가 직접 입력합니다.

  • 생산일자, LOT번호, 제품코드, 제품명, 생산수량, 담당자, 비고

4.2.4 BOM마스터

제품별 원료 구성 비율(Bill of Materials)을 정의합니다.

  • 제품코드, 제품명, 원료코드, 원료명, 사용량, 단위, 비율

4.2.5 원료마스터 / 원료입고

  • 원료마스터: 원료코드, 원료명, 규격, 단위, 공급사, 단가
  • 원료입고: 입고일자, 원료코드, 원료명, 입고량, 단위, 공급사, LOT

4.3 SUMIFS 수식 로직

일별수불부의 F열(사용량)은 로트매칭 시트에서 자동으로 집계됩니다.

=SUMIFS(로트매칭!I:I,        // 합계 대상: 로트매칭 사용량 열
        로트매칭!A:A, $A{row}, // 조건 1: 일자 일치
        로트매칭!F:F, $B{row}) // 조건 2: 원료코드 일치
💡 v3.6.50 수정 관련: 이 수식이 addDailyStockDate 함수에서 잘못된 행 번호($A{row}의 {row})로 생성되어 원료 사용량이 표시되지 않는 버그가 있었습니다. 자세한 내용은 8장: 최근 버그 수정 참조.

5.2 Google Service Account 발급 절차

  1. Google Cloud Console 접속
  2. 새 프로젝트 생성 (또는 기존 프로젝트 선택)
  3. API 및 서비스 → 라이브러리에서 Google Sheets API 사용 설정
  4. IAM 및 관리자 → 서비스 계정 생성
    • 이름: erp-sheets-service
    • 역할: 편집자
  5. 생성된 서비스 계정 → 키 관리 → 키 추가 → 새 키 만들기 (JSON)
  6. 다운로드된 JSON 파일에서 client_email, private_key 값 추출
  7. 중요: Google Sheet를 열어 client_email 주소를 편집자로 공유 추가
💡 Tip: private_key는 \n 개행 문자가 포함된 매우 긴 문자열입니다. Cloudflare Secret에 등록 시 그대로 붙여넣으면 자동으로 처리됩니다.

8.2 근본 원인 및 수정 내역

근본 원인

Silent Write Failure: writeSheetWithFormulas가 호출되었으나 결과값이 검증되지 않고 무조건 성공으로 처리됨. 또한 startRowNum = existingData.length + 2 계산 로직이 시트의 실제 마지막 행과 어긋나서 SUMIFS 수식의 행 번호 참조가 잘못 생성됨.

수정 내역 (v3.6.50)

파일: src/services/GoogleSheetsService.ts (Line 1534-1720)

수정 방식: 3단계 append → parse → rewrite 패턴 적용

// [1단계] placeholder 값으로 append (실제 행 번호 획득 목적)
const placeholderRows = newRows.map(r =>
  [r[0], r[1], r[2], r[3], 0, 0, 0, r[7]]
);
const appendResult = await this.appendSheetWithFormulas(
  '일별수불부', placeholderRows
);

// [2단계] updatedRange를 파싱하여 실제 시작 행 번호 획득
const updatedRange = appendResult.updates?.updates?.updatedRange || '';
const rangeMatch = updatedRange.match(/[A-Z]+(\d+):/);

if (rangeMatch) {
  const actualStartRow = parseInt(rangeMatch[1], 10);

  // [3단계] 올바른 행 번호로 SUMIFS 수식 재생성
  const correctedRows = newRows.map((r, i) => {
    const rowNum = actualStartRow + i;
    return [
      r[0], r[1], r[2], r[3],
      r[4],  // E열: 이월/입고
      `=SUMIFS(로트매칭!I:I,로트매칭!A:A,$A${rowNum},로트매칭!F:F,$B${rowNum})`,
      `=E${rowNum}-F${rowNum}`,
      r[7]
    ];
  });

  // [4단계] 정확한 범위에 재작성
  const correctRange = `A${actualStartRow}:H${actualStartRow + correctedRows.length - 1}`;
  const writeResult = await this.writeSheetWithFormulas(
    '일별수불부', correctRange, correctedRows
  );

  // ✅ write_success/write_error 반환값 추가
  return {
    success: true,
    write_success: writeResult.success,
    write_error: writeResult.error,
    new_rows: correctedRows.length,
    total_rows: existingData.length + correctedRows.length
  };
}

10. 트러블슈팅 가이드

Q1. 생산실적 등록 후 원료 사용량이 0으로 표시됨

원인 후보:

  • BOM 미등록 (해당 제품코드가 BOM마스터에 없음)
  • 로트매칭 시트 재구성 실패
  • 수불부 F열 SUMIFS 수식이 잘못된 행 번호로 생성됨 (v3.6.50 이전 버그)

해결:

# 1. 최신 버전 확인 (v3.6.50 이상)
git log --oneline -5

# 2. 수불부 재생성
POST /api/sheets/add-daily-stock-date {"date": "2026-08-05"}

# 3. write_success: true 확인

Q2. Google Sheets API 에러 (401 Unauthorized)

원인: Service Account 인증 실패 또는 Sheet 공유 권한 없음

해결:

  • Cloudflare Secret 재확인: npx wrangler pages secret list --project-name bv-erp
  • Google Sheet 공유 목록에 Service Account 이메일이 편집자로 있는지 확인
  • GOOGLE_PRIVATE_KEY의 \n 개행이 온전한지 확인

Q3. 배포 후 사이트가 뜨지 않음

  • 프로젝트명 확인: 반드시 bv-erp
  • 빌드 결과 확인: ls dist/_worker.js (약 1.2MB)
  • Cloudflare 대시보드에서 배포 로그 확인

Q4. D1 마이그레이션 실패

  • API Token 권한 확인 (D1: Edit 필요)
  • 중복 마이그레이션 이름 확인 (0001~0015 유일해야 함)
  • 로컬 우선 테스트: --local 플래그 사용

Q5. 8월 이후 D1 데이터가 없음

알려진 이슈: 2026년 6월 10일 이후 D1 데이터 기록이 중단된 상태입니다. 바코드, 품질검사 등 D1 기반 기능이 영향받을 수 있으며, 근본 원인 조사가 보류 상태입니다. Google Sheets 기반 기능(생산/수불부)은 정상 동작합니다.
