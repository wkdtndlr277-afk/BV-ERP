# 🚀 본비반트 ERP 자동화 설치 가이드

## 개요

이 스크립트 **하나만 설치하면** 모든 자동화가 작동합니다:

| 기능 | 트리거 | 설명 |
|------|--------|------|
| ✅ FEFO 자동 실행 | 생산실적 입력 시 | 원료 LOT 자동 매칭 + 잔량 차감 |
| ✅ 익일 출고일지 | 생산실적 입력 시 | 생산일+1 = 출고일 자동 생성 |
| ✅ 일별수불부 | 생산실적 입력 시 | BOM × 수량 = 원료 사용량 자동 계산 |
| ✅ 출고 확정 | 매일 오전 7시 | 출고예정 → 출고완료 + 재고 차감 |

---

## 📋 설치 방법 (5분)

### Step 1: Google Sheets 열기

1. 본비반트 ERP 스프레드시트 열기
2. 상단 메뉴 → **확장 프로그램** → **Apps Script** 클릭

### Step 2: 코드 복사

1. `auto-sync-complete.gs` 파일 내용 전체 복사
2. Apps Script 편집기에 붙여넣기
3. 기존 코드가 있다면 전체 대체

### Step 3: 저장 및 권한 승인

1. **저장** 버튼 클릭 (Ctrl+S)
2. 함수 선택: `setupAutoTriggers`
3. **실행** 버튼 클릭
4. **권한 검토** 팝업에서 Google 계정 선택
5. **허용** 클릭

### Step 4: 완료 확인

```
✅ 자동화 설정 완료!

• 생산실적 입력 시 → FEFO 자동 실행
• 생산실적 입력 시 → 익일 출고일지 자동 생성
• 매일 오전 7시 → 전일 생산분 일괄 처리
```

## 🔧 필요한 시트 구조

### 1. 생산실적 (트리거 대상)

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| 생산일 | 제품코드 | 제품명 | 수량 | LOT번호 | 작업자 | 채널 |

**중요**: D열(수량) 입력 시 자동화가 실행됩니다.

### 2. 원료입고

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| 입고일 | 품목코드 | 품목명 | LOT번호 | 입고량 | 단위 | 공급처 | 유통기한 | 잔량 |

### 3. BOM마스터

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| 제품코드 | 제품명 | 원료코드 | 원료명 | 배합비(g) | 단위 |

### 4. 자동 생성되는 시트

- **로트매칭**: FEFO 실행 기록
- **출고일지**: 익일 출고 예정/완료
- **일별수불부**: 원료 사용량 집계
- **제품재고**: 제품 현재고

| ✅ 오늘 출고 확정 | 수동 출고 확정 |

## ⚙️ 설정 변경

`CONFIG` 객체에서 설정 변경 가능:

```javascript
const CONFIG = {
  SHEETS: {
    PRODUCTION: '생산실적',    // 시트 이름 변경 가능
    INBOUND: '원료입고',
    // ...
  },
  
  EXCLUDE_MATERIALS: ['RM184'],  // FEFO 제외 원료 (정제수 등)
  
  AUTO: {
    FEFO_ON_PRODUCTION: true,      // false = FEFO 자동 실행 끄기
    SHIPMENT_ON_PRODUCTION: true,  // false = 출고일지 자동 생성 끄기
    DAILY_STOCK_ON_PRODUCTION: true // false = 일별수불부 자동 끄기
  }
};
```

## 🔍 트러블슈팅

### Q: 자동화가 작동하지 않아요
1. **트리거 확인**: 편집 → 현재 프로젝트의 트리거 → `onEditTrigger` 있는지 확인
2. **권한 확인**: 다시 `setupAutoTriggers()` 실행하고 권한 승인
3. **시트 이름 확인**: CONFIG의 시트 이름과 실제 시트 이름 일치하는지

### Q: FEFO가 실행되지 않아요
1. **BOM 확인**: BOM마스터에 해당 제품코드가 있는지
2. **원료 재고 확인**: 원료입고 시트에 잔량이 있는지
3. **로그 확인**: Apps Script → 실행 → 실행 기록에서 에러 확인

### Q: 출고일지가 중복 생성돼요
- 정상입니다! 중복 체크가 되어있어 같은 건은 추가 안 됩니다.
- 수동으로 삭제 후 재생성하려면 메뉴에서 실행하세요.
