# 출고 프로세스 자동화 시스템 - 설치 및 사용 가이드

## 📋 개요

본비반트 ERP의 **주문 생산 방식** 출고 자동화 시스템입니다.
생산일보 입력 시 자동으로 주문을 매칭하고 출고 처리합니다.

## 🔄 업무 흐름

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  주문 접수   │ →  │ 생산일보    │ →  │ 자동 매칭   │ →  │ 출고 확정   │ →  │ 배송 준비   │
│  (주문_RAW)  │    │ (생산실적)  │    │ (출고대기)  │    │ (출고완료)  │    │ (배송상태)  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 🔧 설치 방법

### 1단계: Apps Script 열기

1. Google Sheets 스프레드시트 열기
2. 메뉴: **확장 프로그램** → **Apps Script**

### 2단계: 코드 복사

1. `shipment-process.gs` 파일 내용 전체 복사
2. Apps Script 편집기에 붙여넣기
3. **Ctrl + S** 저장

### 3단계: 트리거 설치 (중요!)

자동 매칭을 위해 **반드시** 트리거를 설치해야 합니다.

**방법 A: 함수 실행**
1. Apps Script에서 `installOnEditTrigger` 함수 선택
2. ▶️ 실행 버튼 클릭
3. 권한 승인

**방법 B: 수동 설정**
1. Apps Script 왼쪽 메뉴 ⏰ **트리거** 클릭
2. **트리거 추가** 클릭
3. 설정:
   - 실행할 함수: `onProductionEdit`
   - 이벤트 소스: `스프레드시트에서`
   - 이벤트 유형: `수정 시`
4. **저장**

### 4단계: 시트 초기화

1. 스프레드시트로 돌아가기
2. 메뉴: **📦 출고관리** → **🔧 시트 초기화**
3. 필요한 시트가 자동 생성됩니다

| B | 채널 | 판매 채널 | coupang |
| C | 제품코드 | 제품 코드 | BRD001 |

| 열 | 필드명 | 설명 | 예시 |
|----|--------|------|------|
| A | 생산일 | 생산 완료일 | 2026-06-24 |
| B | 제품코드 | 제품 코드 | BRD001 |
| C | 제품명 | 제품명 | 통밀식빵 |

| H | 매칭주문 | (자동) | ORD-2 |

### 3. 출고대기 (자동 생성)
매칭된 출고 대기 항목 목록

### 4. 출고완료 (자동 생성)
출고 확정된 이력 보관

### 5. 제품재고 (자동 생성)
일별 제품 재고 현황

## 🎯 사용 방법

### 일일 작업 순서

#### 1️⃣ 주문 입력 (09:00)
```
주문_RAW 시트에 당일 접수된 주문 입력
- 발주서 업로드 또는 수동 입력
- 상태: '대기' (기본값)
```

#### 2️⃣ 생산일보 입력 (17:00)
```
생산실적_RAW 시트에 생산 완료 수량 입력
- 제품코드, 수량, LOT번호 입력
- 저장 즉시 자동 매칭 실행
```

#### 3️⃣ 매칭 결과 확인 (17:05)
```
출고대기 시트에서 확인
- 출고대기: 전량 매칭 완료
- 부분출고대기: 일부만 매칭
```

#### 4️⃣ 출고 확정 (17:10)
```
메뉴: 📦 출고관리 → 🔄 선택항목 출고 확정
- 또는: 📋 전체 출고대기 확정
```

#### 5️⃣ 배송 준비 (17:30)
```
출고완료 시트에서 배송 상태 관리
- 송장번호 입력
- 상태 변경: 배송준비 → 배송중 → 배송완료
```

## 📈 자동 매칭 로직

### 매칭 우선순위 (FIFO)
1. **완전 일치**: 제품코드 + 채널 + 납품일
2. **채널 일치**: 제품코드 + 채널
3. **제품 일치**: 제품코드만

### 수량 처리

| 상황 | 처리 | 결과 상태 |
|------|------|-----------|
| 생산 >= 주문 | 전량 매칭 | 출고대기 |
| 생산 < 주문 | 생산분만 매칭 | 부분출고대기 |
| 주문 없음 | 재고 입고 | 재고입고 |

### 예시

```
주문: 통밀식빵 100개 (coupang)
      통밀식빵 80개 (kurly)

생산: 통밀식빵 150개 (coupang)

결과:
- 주문1(coupang) → 100개 매칭 → '출고대기'
- 주문2(kurly) → 50개 매칭 → '부분출고대기' (30개 부족)
- 잔여 0개 → 재고 없음
```

## 🛠️ 문제 해결

### Q: 자동 매칭이 안 됩니다
**A:** 트리거가 설치되었는지 확인하세요.
- Apps Script → 트리거 → `onProductionEdit` 확인
- 없으면 `installOnEditTrigger` 함수 실행

### Q: 채널이 맞지 않습니다
**A:** 채널명 표기 통일 필요
- 영문: coupang, kurly, bmart, oasis
- 또는 한글: 쿠팡, 컬리, 배민, 오아시스

### Q: 주문이 매칭되지 않습니다
**A:** 다음 사항 확인:
1. 주문 상태가 '대기' 또는 '부분출고대기'인지
2. 제품코드가 정확한지
3. 채널이 일치하는지

### Q: 재고가 안 맞습니다
**A:** 제품재고 시트 확인
- 생산입고(+)와 출고(-)가 올바른지
- 수동 조정 필요 시 직접 수정
