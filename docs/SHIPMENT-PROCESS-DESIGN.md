# 본비반트 ERP 출고 프로세스 설계

## 📋 개요

**주문 생산 방식**: 생산일보가 모든 출고의 시작점
- 생산일보 입력 → 주문 매칭 → 재고 차감 → 출고 처리 → 배송 준비

## 🔄 업무 흐름도

```

                [부분출고대기] ──────────────────┤
                        │                        │
                        │ (추가생산 후)           │
                        ▼                        │
                   [출고대기] ◄──────────────────┘
                        │
                        ▼ (출고 확정)
                   [출고완료]
                        │
                        ▼ (배송)
                   [배송준비]
                        │
                        ▼
                    [배송중]
                        │
                        ▼
                   [배송완료]
```

### 생산 상태
```
[생산완료] ──► [주문매칭중] ──► [출고대기] ──► [출고완료]
                    │
                    │ (주문 없음)
                    ▼
                [재고보관]
```

## 🎯 핵심 매칭 로직

### 생산일보 → 주문 매칭 우선순위

1. **완전 일치**: 제품코드 + 채널 + 납품일
2. **채널 일치**: 제품코드 + 채널 (FIFO: 먼저 주문된 것부터)
3. **제품 일치**: 제품코드만 (채널 무관, FIFO)
4. **미매칭**: 재고로 보관

### 수량 처리 로직

```javascript
생산수량 = 150
대기주문 = [
  { 주문A: 100 },
  { 주문B: 80 }
]

// 매칭 결과
if (생산수량 >= 주문A) {
  주문A → 전량매칭 (100) → '출고대기'
  잔여 = 150 - 100 = 50
}
if (잔여 >= 주문B) {
  주문B → 전량매칭 (50) → '부분출고대기' (80중 50만)
  미충족 = 80 - 50 = 30 → '대기' 유지
} else {
  잔여 → 재고 보관
}
```

## 📈 정합성 체크 규칙

### 1. 생산수량 vs 주문수량
| 조건 | 처리 | 상태 |
|------|------|------|
| 생산 >= 주문 | 전량 출고 가능 | 출고대기 |
| 생산 < 주문 | 생산분만 부분 출고 | 부분출고대기 |
| 생산 > 0, 주문 = 0 | 재고 보관 | 재고입고 |

### 2. 일일 마감 체크
- 미처리 주문 리스트 자동 생성
- 생산 부족 품목 알림
- 익일 생산 계획 연동

### 3. 재고 정합성
- 생산입고 수량 = 출고 수량 + 재고 증가
- 음수 재고 발생 시 자동 차단
- 일일 재고 스냅샷 저장

## 🛠️ 구현 컴포넌트

### Google Apps Script
1. **onEditTrigger.gs**: 생산실적 입력 감지
2. **orderMatching.gs**: 주문 자동 매칭
3. **shipmentProcess.gs**: 출고 처리 및 재고 차감
4. **dailyReport.gs**: 일일 마감 리포트

### ERP API 연동
1. `POST /api/shipment/process`: 출고 확정 처리
2. `GET /api/shipment/pending`: 출고 대기 목록
3. `POST /api/shipment/complete`: 배송 완료 처리
4. `GET /api/shipment/daily-summary`: 일일 출고 요약

## 📝 사용자 작업 가이드

### 일일 작업 순서

1. **09:00** - 전일 발주서 확인 (자동 업로드된 주문)
2. **17:00** - 생산일보 입력 (생산실적_RAW)
3. **17:05** - 자동 매칭 결과 확인 (출고대기 시트)
4. **17:10** - 출고 확정 처리 (출고대기 → 출고완료)
5. **17:30** - 배송 준비 완료 확인
